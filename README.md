## Алгоритм № 24. Линейный поиск первого вхождения

**Условие:** найти первое вхождение заданного значения `x` при просмотре массива слева направо.

**Ограничения:** `1 ≤ n ≤ 100`; массив `A[1..n]` из целых чисел; целое `x`.
Если `n < 1` или `n > 100` — вывод «Ошибка входных данных».

**Выход:** наименьший индекс найденного элемента (1..n) либо «Элемент не найден».

**Переменные:** `n` — размер массива; `A` — массив; `x` — искомое значение;
`i` — текущий индекс; `found` — флаг (1/0); `pos` — индекс первого вхождения.

**Блок-схема:**

![Блок-схема алгоритма 24](docs/schemes/scheme_24.png)

**Таблица проверки:**

| № | Входные данные | Ожидаемый результат | Результат по схеме | Совпало? |
|---|----------------|---------------------|--------------------|----------|
| 1 | n = 5, A = [4, 7, 2, 7, 9], x = 7 | pos = 2 | pos = 2 | Да |
| 2 | n = 5, A = [4, 7, 2, 7, 9], x = 3 | Элемент не найден | Элемент не найден | Да |
| 3 | n = 1, A = [5], x = 5 | pos = 1 | pos = 1 | Да |
| 4 | n = 0 | Ошибка входных данных | Ошибка входных данных | Да |

**Вывод:** проверены первое вхождение при повторе, отсутствие элемента, минимальный
массив и недопустимое `n`. Ветви «найдено» и «не найдено» достигнуты, результаты совпали.

## Алгоритм № 25. Пузырьковая сортировка

**Условие:** отсортировать массив по неубыванию методом пузырька — сравнивать соседние
элементы и менять их местами, если левый больше правого.

**Ограничения:** `1 ≤ n ≤ 20`; массив `A[1..n]` из целых чисел.
Если `n < 1` или `n > 20` — вывод «Ошибка входных данных».

**Выход:** все элементы отсортированного массива.

**Переменные:** `n` — размер; `A` — массив; `i` — номер прохода; `j` — индекс сравнения;
`temp` — временная переменная для обмена.

**Блок-схема:**

![Блок-схема алгоритма 25](docs/schemes/scheme_25.png)

**Таблица проверки:**

| № | Входные данные | Ожидаемый результат | Результат по схеме | Совпало? |
|---|----------------|---------------------|--------------------|----------|
| 1 | n = 1, A = [5] | [5] | [5] | Да |
| 2 | n = 5, A = [4, 2, 7, 1, 3] | [1, 2, 3, 4, 7] | [1, 2, 3, 4, 7] | Да |
| 3 | n = 3, A = [3, 1, 2] | [1, 2, 3] | [1, 2, 3] | Да |
| 4 | n = 0 | Ошибка входных данных | Ошибка входных данных | Да |

**Вывод:** проверены массив из одного элемента, обычный массив с несколькими проходами,
короткий массив и недопустимое `n`. Обмен через `temp` раскрыт, результаты совпали.

## Алгоритм № 26. Разворот массива на месте

Если `n < 1` или `n > 100` — вывод «Ошибка входных данных».

**Выход:** массив после разворота.

**Переменные:** `n` — размер; `A` — массив; `left` — левый индекс; `right` — правый индекс;
`temp` — временная переменная для обмена.

**Блок-схема:**

## Алгоритм № 27. Проверка порядка в массиве

элемент должен быть не меньше предыдущего.

**Ограничения:** `1 ≤ n ≤ 100`; массив `A[1..n]` из целых чисел.
Если `n < 1` или `n > 100` — вывод «Ошибка входных данных».

**Выход:** «Упорядочен» или «Не упорядочен».

**Переменные:** `n` — размер; `A` — массив; `i` — текущий индекс; `ordered` — флаг (1/0).

**Блок-схема:**

![Блок-схема алгоритма 27](docs/schemes/scheme_27.png)

| 2 | n = 4, A = [1, 2, 2, 5] | Упорядочен | Упорядочен | Да |

## Алгоритм № 28. Строка-палиндром

**Условие:** проверить, одинаково ли строка читается слева направо и справа налево.

**Ограничения:** строка `s` длиной от 1 до 100 символов, только строчные латинские буквы
без пробелов. Если длина меньше 1 или больше 100 — вывод «Ошибка входных данных».

**Выход:** «Палиндром» или «Не палиндром».

**Переменные:** `s` — строка; `left` — левый индекс; `right` — правый индекс; `pal` — флаг (1/0).

## Алгоритм № 29. Количество гласных в строке

**Условие:** подсчитать количество вхождений гласных букв в строке. Гласными считаются
только `a, e, i, o, u`.

**Ограничения:** строка `s` длиной от 0 до 100 символов, только строчные латинские буквы
и пробелы. Если длина больше 100 — вывод «Ошибка входных данных».

**Выход:** количество гласных с учётом повторов. Для пустой строки — `0`.

**Переменные:** `s` — строка; `i` — текущий индекс; `count` — счётчик гласных.

**Блок-схема:**

![Блок-схема алгоритма 29](docs/schemes/scheme_29.png)

## Алгоритм № 30. Правильная скобочная последовательность

**Условие:** проверить правильность строки из круглых скобок — каждая закрывающая скобка
должна иметь предшествующую непарную открывающую, а после обработки всей строки
непарных скобок не остаётся.

**Ограничения:** строка `s` длиной от 0 до 100 символов, допустимы только символы `(` и `)`.
Если длина больше 100 — вывод «Ошибка входных данных».

**Выход:** «Правильная» или «Неправильная». Пустая строка считается правильной.

**Переменные:** `s` — строка; `i` — текущий индекс; `balance` — баланс скобок;
`valid` — флаг (1/0).

**Блок-схема:**

![Блок-схема алгоритма 30](docs/schemes/scheme_30.png)

**Таблица проверки:**

| № | Входные данные | Ожидаемый результат | Результат по схеме | Совпало? |
|---|----------------|---------------------|--------------------|----------|
| 1 | s = "" | Правильная | Правильная | Да |
| 2 | s = "()" | Правильная | Правильная | Да |
| 3 | s = "(())" | Правильная | Правильная | Да |
| 4 | s = ")(" | Неправильная | Неправильная | Да |
| 5 | s = "(()" | Неправильная | Неправильная | Да |
| 6 | s длиной 101 | Ошибка входных данных | Ошибка входных данных | Да |

**Вывод:** проверены пустая строка, простая правильная последовательность, вложенная
правильная последовательность, нарушение порядка, незакрытая скобка и недопустимая длина.
Все достижимые ветви проверены, результаты совпали.
